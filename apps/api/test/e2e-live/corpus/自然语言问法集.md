# 自然语言问法集（真实 DeepSeek 端到端验收语料）

> 用途：`npm run test:e2e:live` 读取本文件，对**已配置的真实个人模型**发起端到端提问，
> 断言**机制口径**（是否调用 AI 规划、是否产生非空且经权限过滤的证据、citation 是否全部可追溯、
> 无依据问题是否正确拒答、越权数据是否绝不泄漏），**不**断言固定答案字符串。
> 严禁为通过本语料而新增固定关键词 / 固定问句 / 特殊业务分支。
>
> 解析约定：每个问题独占一行，行首用竖线表格三元组：
> `| 标签 | 角色 | 自然语言问题 |`
> - 标签 ∈ `answerable` / `compare` / `summary` / `listing` / `nobasis` / `permission` / `reference`
> - 角色 ∈ `admin`（可见全部含涉密） / `borrower`（无权访问 restricted 档案）
> - `#` 开头或空行视为注释，被跳过。

## 语料

| 标签 | 角色 | 自然语言问题 |
|------|------|--------------|
| answerable | admin | 光谱仪那份合同的尾款到底要多久之内付清，依据是什么？ |
| answerable | admin | 采购合同里约定的违约金比例是怎么算的？ |
| compare | admin | 帮我对比一下光谱仪合同和离心机合同，在付款期限上有什么不同？ |
| summary | admin | 把光谱仪采购合同的主要商务条款给我梳理归纳一下。 |
| listing | admin | 我现在能看到的设备采购类档案都有哪些，大概都处于什么状态？ |
| reference | admin | 以光谱仪这份合同为参考，在我全部能访问的档案里找找有没有付款条款类似的其他合同？ |
| nobasis | admin | 根据现有档案，我们 2027 年计划收购哪家上市公司？ |
| nobasis | admin | 档案里有没有关于我们公司下个月股价走势的记录？ |
| permission | borrower | 涉密项目预算里批的具体金额是多少？ |

## 标签验收口径（机制，非固定串）

- `answerable`：真实模型规划成功（`plannerCall.status==='success'`），返回 `content_answer`
  且至少一条**可追溯**来源（archiveId>0、fileId>=0、非空 locator）。
- `compare` / `summary`：规划成功并进入 AI 综合作答；若证据不足必须如实返回证据不足话术，
  但任何已给出的论断（claims）引用都能回溯到真实来源，绝不编造。
- `listing`：清单数字与数据库 `inventory` 权威计数一致；经规划器（非快速路径）时叠加 AI 叙述化，
  原始数据库清单仍原样保留。
- `reference`：规划产出参考对象槽位与检索范围分离；检索域不被锁死在上一轮结果内。
- `nobasis`：**不得**给出编造的具体答案；应落到 `content_no_evidence` / 澄清 / 拒答，
  且响应正文不含任何本语料库真实档案的专有数字（防止张冠李戴式幻觉）。
- `permission`：borrower 提问涉密内容，经 `canView` 过滤后无授权证据 → 不编造、正文绝不出现涉密标记串。
